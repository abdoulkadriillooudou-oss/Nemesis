About Me

I am Illo Oudou Abdou Kadri, known as Kadri Illo, an IT Manager and developer from Niger. I work with the NGO Sahel Développement Niger, an affiliate of the Africa Career Networks (ACN) programme, where I support participants on their path to internships and jobs and engage partner employers.

As a developer, I enjoy the full journey of an application: designing the database, building the Spring Boot services behind it, creating the interface people use, and packaging everything with Docker so it runs the same way everywhere.

On the web I write semantic, accessible and responsive HTML and CSS. On mobile I build cross-platform apps with Flutter. I care about clean structure, readable code and technology that solves real local needs.

How I Build for the Web

  1. Semantic & accessible

    Meaningful HTML5 structure, ARIA landmarks and descriptive alt text so every visitor can navigate the page.

  2. Organized CSS

    BEM naming and CSS custom properties keep stylesheets consistent and easy to maintain.

  3. Flexible layouts

    Flexbox and Grid used together for navigation, cards and full page structure.

  4. Mobile-first & responsive

    Designed for small screens first, then enhanced with media queries, fluid type and flexible images.

  5. Purposeful motion

    Transitions, transforms and keyframe animations that add polish without getting in the way.
